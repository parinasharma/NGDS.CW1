# Appliances Energy Consumption Prediction Using Machine Learning

## 📌 Project Overview

This project explores machine learning techniques for predicting household appliance energy consumption using time-based features, indoor sensor measurements, and weather conditions.

Using the Appliances Energy Prediction dataset, the project covers data preprocessing, feature engineering, dimensionality reduction with Principal Component Analysis (PCA), model training, hyperparameter tuning, Explainable AI (XAI), and anomaly detection.

Two prediction approaches are investigated: predicting consumption from environmental and time-related features, and short-term forecasting using recent consumption readings.

## 🎯 Objectives

- Analyse appliance energy consumption patterns.
- Preprocess and prepare time-series data.
- Engineer useful temporal and sensor-based features.
- Apply PCA to explore relationships between features.
- Compare machine learning regression models.
- Improve model performance through hyperparameter tuning.
- Interpret predictions using SHAP and feature importance.
- Identify unusual observations using residual analysis and Isolation Forest.
- Compare conditions-only prediction with short-term forecasting.
